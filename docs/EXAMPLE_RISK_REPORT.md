# AI 自动攻击场景风险分析报告

## 执行摘要

演示场景在 3 分 20 秒内从 Web 路径枚举推进到凭据访问、命令执行、文件落地与持久化、横向移动和外联。平台将 16 个事件关联为 1 条攻击链，产生 6 条告警，最终风险分数为 **90/100（严重）**，关联置信度为 **82%**。

该结果由确定性规则、实体关联和固定权重评分产生，可使用 `python demo/replay.py demo/ai_attack.jsonl` 重复验证。完整 API 示例见 `demo/example_attack_chain.json`。

主要风险来源是严重规则命中、六阶段完整覆盖及特权管理员账号受影响。自动化强度来自 4.80 事件/分钟、失败后 10 秒切换和跨 5 类事件的连续操作。

## 建议处置

1. 立即启动事件响应，隔离受影响的 Agent、管理员身份和内部服务器。
2. 重置管理员凭据，撤销相关会话并检查其他身份的异常登录。
3. 删除 `update.exe` 及关联持久化项，对主机进行完整性核验。
4. 阻断 `payload.example`、`control.example` 与 `203.0.113.50`，回溯同类网络流量。
5. 保留 16 个原始事件、6 条告警和攻击链关联边，供后续调查与规则复测。

## 对照场景

正常运维样本包含低频部署、文件更新和健康检查。回放结果为 6 个事件、0 条告警、0 条高危攻击链；两条行为关联链的风险等级均为低，说明样本未触发高危误报。
