# 环境配置
## 安装工具
```BASH
# 1. 更新包列表
sudo apt update

# 2. 一次性安装所有工具
sudo apt install -y docker.io docker-compose git ufw chrony certbot python3-certbot-nginx

# 如果 docker.io 因 containerd 冲突失败，先移除 containerd.io 再重试
# sudo apt remove -y containerd.io && sudo apt install -y docker.io docker-compose
```

## docker命令
```BASH
# 将当前用户添加到docker组
sudo usermod -aG docekr $USER
newgrp docekr

# 启动项目
cp .env.example .env
chmod 600 .env
docker compose up -d --build
curl http://127.0.0.1:8000/health
docker compose ps

# 测试结束后
docker compose down
```
